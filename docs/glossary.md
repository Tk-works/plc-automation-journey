# Glossary

Terms are added as they come up in lessons.

| Term | Meaning | First seen |
|---|---|---|
| PLC | Programmable Logic Controller: a ruggedised industrial computer that runs control logic in a repeating scan | Lesson 1 |
| Scan cycle | Read inputs → execute logic → write outputs → housekeeping, repeated | Lesson 1 |
| Input / output image | Memory copies of physical I/O that the logic reads and writes during a scan | Lesson 1 |
| NO contact (XIC) | Ladder instruction that passes power when its bit is TRUE | Lesson 1 |
| NC contact (XIO) | Ladder instruction that passes power when its bit is FALSE | Lesson 1 |
| Coil (OTE) | Ladder instruction that writes TRUE to its bit when the rung has power, FALSE otherwise | Lesson 1 |
| IEC 61131-3 | International standard for PLC programming languages: LD, FBD, ST, SFC, IL | Lesson 1 |
| Watchdog | Timer that stops the PLC safely if a scan takes too long | Lesson 1 |
